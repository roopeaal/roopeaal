## About

I am an ICT Engineering student focused on networks, Linux, cloud fundamentals, IoT systems and practical security testing. I like projects where software has to meet real systems: embedded hardware, network labs, databases, deployment pipelines and user-facing interfaces.

This GitHub profile collects selected course and personal projects that show how I build, test, document and improve real technical work.

## Focus Areas

- Network fundamentals, lab environments and segmentation testing
- Linux, servers, troubleshooting and practical system work
- Embedded systems with Raspberry Pi Pico / Pico W
- IoT device control, sensors and hardware integration
- Web applications with Python, Flask, MySQL, React and Next.js
- Security awareness, phishing simulation and identity-risk thinking
